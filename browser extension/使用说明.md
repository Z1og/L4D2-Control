# L4D2 百度直链助手 / L4D2 Baidu Direct Download Helper

这是适用于 Chrome、Edge 及其他支持 Manifest V3 的 Chromium 浏览器的本地扩展。它能让百度网盘直链从百度直接下载到你的电脑，不经过游戏服务器。

## 安装（Chrome / Edge）

1. 登录 L4D2-Control，在“云端地图 → 下载器直连”下载扩展 ZIP 和本说明。
2. 将 ZIP 解压到不会被清理的本地文件夹。
3. 在 Chrome 打开 `chrome://extensions`，或在 Edge 打开 `edge://extensions`。
4. 开启“开发者模式”，选择“加载已解压的扩展程序”，选择包含 `manifest.json` 的扩展文件夹。
5. 回到 L4D2-Control 面板标签页，点击工具栏扩展图标（必要时先固定扩展），选择“绑定当前面板标签页”。
6. 在该面板标签页打开云端地图的直连对话框，点击“浏览器直接下载”。

开发者模式 ZIP 是已解压扩展的源文件包，不是双击安装的 CRX，也不是浏览器商店安装包。

## 作用范围与隐私

- 规则限定绑定时的面板来源域名、当前标签页 ID 和 `*.baidupcs.com` / `*.pcs.baidu.com` 下载域名，并将匹配请求的 User-Agent 设为 `pan.baidu.com`。
- 其他标签页、网站、浏览器应用和服务器流量不受影响；扩展不配置代理。
- 扩展不读取网页正文、不储存下载链接或网盘凭据，也不向第三方发送数据。
- 下载文件从百度直接传到你的电脑。实际速度仍取决于百度及本地网络。
- 扩展规则只保存在当前浏览器会话中。浏览器重启、扩展重新加载或更新后，需要重新绑定。
- 百度可能调整直链域名或请求策略；如果下载失败，可使用对话框提供的 Windows curl / aria2 本机直连命令。

## English

This local extension works with Chrome, Edge and other Chromium browsers that support Manifest V3. It lets a Baidu direct link download from Baidu straight to your computer, bypassing the game server.

### Install

1. Sign in to L4D2-Control and open **Cloud Maps → Direct downloader**. Download the ZIP and this guide.
2. Extract the ZIP into a local folder that will not be cleaned up.
3. Open `chrome://extensions` in Chrome or `edge://extensions` in Edge.
4. Enable **Developer mode**, choose **Load unpacked**, and select the extension folder containing `manifest.json`.
5. Return to the L4D2-Control panel tab, click the toolbar extension icon (pin it first if needed), then choose **Bind this panel tab**.
6. In that same panel tab, open the Cloud Maps direct-download dialog and click **Browser direct download**.

The developer-mode ZIP contains unpacked extension source files. It is not a double-click CRX or a browser-store installer.

### Scope and privacy

- Rules are limited to the panel origin selected at binding time, that tab ID, and `*.baidupcs.com` / `*.pcs.baidu.com`; matching requests receive the `pan.baidu.com` User-Agent.
- Other tabs, websites, browser apps and server traffic are unaffected. The extension does not configure a proxy.
- It does not read page content, store download links or cloud credentials, or send data to third parties.
- The file downloads directly from Baidu to your computer. Speed still depends on Baidu and your local network.
- Rules exist only for the current browser session. Rebind after restarting the browser or reloading/updating the extension.
- If Baidu changes its direct-link hosts or request policy, use the Windows curl / aria2 local-download command in the dialog instead.
