L4D2-CONTROL · BAIDU DIRECT DOWNLOAD

浏览器直连扩展

让百度网盘文件从百度直接下载到你的电脑，不经过游戏服务器。下载速度仍取决于百度和本地网络。

下载扩展 ZIP返回面板

Chrome / Edge 安装步骤

  1. 下载 ZIP 并解压到不会被清理的本地文件夹。
  2. 打开 chrome://extensions 或 edge://extensions，启用“开发者模式”。
  3. 选择“加载已解压的扩展程序”，选中包含 manifest.json 的扩展文件夹。
  4. 回到面板标签页，点击浏览器工具栏的扩展图标，选择“绑定当前面板标签页”。
  5. 在同一面板标签页点击“浏览器直接下载”。
范围与隐私
规则仅针对用户绑定的面板来源、该标签页及百度下载域名，设置下载所需的 pan.baidu.com User-Agent。不配置代理、不读取网页正文、不保存下载链接或凭据。规则在浏览器重启后失效，重新绑定即可。ZIP 是开发者模式扩展源文件，不是 CRX 商店安装包。
ENGLISH

Install in Chrome / Edge

This extension lets Baidu files download directly to your computer instead of passing through the game server.

  1. Download the ZIP and extract it to a persistent local folder.
  2. Open chrome://extensions or edge://extensions and enable Developer mode.
  3. Select Load unpacked and choose the folder containing manifest.json.
  4. Return to the panel tab, click the extension toolbar icon and choose Bind this panel tab.
  5. Click Browser direct download from that same panel tab.
Scope and privacy
Rules apply only to the manually bound panel origin, tab ID and Baidu download hosts. No proxy is configured; page content, links and credentials are not stored or sent elsewhere. Rebind after restarting the browser. The ZIP is unpacked developer-mode source, not a CRX or store installer.
